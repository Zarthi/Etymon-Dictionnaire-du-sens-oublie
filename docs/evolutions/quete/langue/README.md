# Une langue qui ne se parle pas

> Évolution future, dans la [Quête](../README.md), hors des fiches. Neuvième état. Les lettres
> sont dans `lettres.yaml`, les triangles des traditions dans `triangles.yaml`, les mots dans
> `mots/`. Le journal des états est à la fin.

Une langue de signes qui ne se parle pas : elle se lit. Un signe, dit Augustin, est « une chose qui,
outre l'apparence qu'elle offre aux sens, fait venir d'elle-même autre chose à la pensée » (*De la
doctrine chrétienne*, II, 1, 1). Ses règles ne valent que pour elle : les fiches restent un ordre
de textes.

## Deux langues, l'une valeur de l'autre

**Le Centre**, la langue des principes. Ses lettres sont des figures : une grille de trois sur
trois, chaque case pleine ou vide. Une lettre ne représente rien, elle est sa figure, et son sens
est celui de son nombre et de sa disposition, que la grille donne d'elle-même. Un mot est une
succession de lettres, lue de gauche à droite : une suite de principes, un devenir ; une lettre
seule est un état.

**Le Pourtour**, la langue des participations. Les choses du monde, écrites en emoji, que tous les
téléphones ont : 🔥, ⛰️, 😈, la manne. Un récit en Pourtour se lit comme une histoire, et chaque
chose y a pour valeur une lettre du Centre, sa participation aux principes ; le récit a pour valeur
le mot. Comme chaque lettre hébraïque est un nombre et chaque mot une somme ; comme « les
perfections invisibles se voient, comprises par les choses faites » (Romains 1, 20, de mémoire).

La participation d'une chose (quelle lettre vaut le feu) est une lecture, signée, par tradition :
le feu n'a pas la même figure partout. Le Centre est commun ; le Pourtour est à chacun. Le Centre
n'écrit jamais le monde ; le Pourtour ne fonde rien.

Les deux noms sont ceux des lettres 1 et 8 : le centre seul, l'Un ; le pourtour sans le centre, le
monde autour du principe. Ensemble, la lettre 9, le tout.

## Le fondement : la géométrie, et rien d'autre

La grille est la croix : le centre, où l'axe perce le plan ; la colonne, l'axe, le haut, le milieu,
le bas ; la ligne, le plan, l'avant, le présent, l'après ; les quatre coins, la seconde croix, les
directions intermédiaires. La colonne dit ce qui est, la ligne ce qui devient (Guénon, *Le
Symbolisme de la croix*, ch. II, vérifié : « horizontalement, à un certain degré d'existence
déterminé ; verticalement, dans la superposition hiérarchique de tous les degrés ») ; le centre est
le même point, milieu dans l'être, présent dans le temps.

**La grille vide n'est pas une lettre** : c'est le Principe, qui n'a pas de signe (Exode 20, 4).
Le centre seul est l'Un, sa première détermination : le Tao produit l'Un (*Tao Te King*, 42, de
mémoire). Plein ou vide, c'est la première séparation, la lumière et les ténèbres (Genèse 1, 4,
vérifié) : la langue est binaire parce que la première distinction l'est.

Les trois premières lettres de l'axe (le centre ; le haut et le bas en face ; la colonne) sont le
**triangle de trois**, le symbole métaphysique sur lequel toutes les traditions relevées
s'accordent : un principe, deux contraires, le milieu qui les sépare (`triangles.yaml`). Le
quatrième rang, la manifestation, est ce qui les sépare ; il n'est pas dans le Centre, il est dans
le Pourtour.

Les textes confirment, ne fondent pas : « la lettre tue, l'esprit vivifie » (2 Corinthiens 3, 6).

## Ce que dit chaque lettre

Les lettres sont les figures que la grille répartit symétriquement ; elles vont par paires selon
l'orientation. Dix-neuf, sans la grille vide (`lettres.yaml`).

| Cases | Lettres | Ce que la géométrie en dit |
|---|---|---|
| 1 | le centre | l'Un |
| 2 | deux cases en face (verticale, horizontale, deux diagonales) | une dualité, deux contraires ; le rang 2 n'a pas de centre |
| 3 | la colonne, la ligne, deux diagonales | les extrêmes et, entre eux, le point de l'axe ; en colonne, ce qui est ; en ligne, ce qui devient |
| 4 | les bras, les coins | le cycle vu en lui-même, sans centre : les bras, un carré posé sur un angle, le cycle dans ce qu'il a de mouvant ; les coins, un carré posé sur sa base, le cycle dans ce qu'il a de stable. En face, deux paires de contraires ; autour, dans le sens horaire depuis le haut, la suite qui revient |
| 5 | la croix, le × plein | la croix : la verticale qui croise l'horizontale en son centre, ce qui est et ce qui devient en un même point (les bras sont sur les axes, ils se lisent comme des lignes) ; le × : le cycle et son centre (les coins ne sont sur aucun axe, ils se lisent comme des points autour) |
| 6 | deux lignes, deux colonnes | deux « ce qui devient », le plan d'en haut et celui d'en bas, séparés ; ou deux « ce qui est », deux totalités séparées |
| 7 | le I, le H | le six et son lien : les deux plans reliés par l'axe, le firmament entre les eaux (Genèse 1, 6-7, vérifié) ; ou les deux totalités reliées par un pont en leur milieu |
| 8 | le pourtour | le cercle entier autour du point |
| 9 | le tout | le centre et tout ce qui l'entoure |

Le sens de lecture : le haut d'abord, puis vers la droite ; d'où le sens horaire sur la croix. La
même figure lue à rebours dit le retour.

## La lecture

Chaque mot est accompagné d'une lecture, toujours signée : par le lecteur qui la fait, dans la
Quête, sur son appareil seulement ; ou par la tradition qui la porte, par ses textes cités. Aucune
règle de composition : la suite est le temps, la figure est le sens, le reste est lecture.

## Précédents

Dans `precedents.md`. Le *Yi Jing* est le plus proche, et il est vérifié : ses huit trigrammes
autour du centre se lisent en face (quatre paires de contraires) et autour (le cycle de l'année),
qui sont nos deux lectures ; et une colonne de trois cases est un trigramme. Le reste (braille,
Sefer Yetzirah, Lulle, Wilkins, Leibniz, Bliss) est de mémoire, à vérifier.

   **lettre**, non le mot ; chaque longueur de 1 à 9 a sa figure et son sens. Deux langues : le
   Centre (figures binaires, principes) et le Pourtour (emoji, participations, par tradition), le
   second ayant le premier pour valeur. Les signes ne sont plus à choisir : ce sont des figures. La
   grille vide est le Principe.

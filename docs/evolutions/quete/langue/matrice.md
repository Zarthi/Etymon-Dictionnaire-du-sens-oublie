# La matrice de trois : où s'écrivent les mots

> Ce qui a été décidé sur la grille 3 × 3, la croix qu'on y occupe, et ce que dit chaque
> longueur de mot. Les triangles sont dans `triangles.yaml`, les mots dans `mots/`.

Un mot s'écrit dans une grille de trois sur trois. Il occupe la croix : le centre, la colonne, la
ligne. Les quatre coins, les diagonales, sont fermés.

```
    .   H   .
    G   C   D
    .   B   .
```

La colonne est l'axe : le haut, le milieu, le bas. La ligne est le plan : l'avant, le présent,
l'après. La colonne dit ce qui est, la ligne ce qui devient ; l'une est un principe dans l'être,
l'autre dans le temps. Le centre est le même point de l'axe, milieu dans l'être, présent dans le
temps.

## Ce que dit chaque longueur

La longueur d'un mot est le rang qu'il occupe ; la géométrie du rang donne sa lecture.

| Signes | Rang | Où | Lecture |
|---|---|---|---|
| 1 | 1 | le centre | l'Un, la première détermination : un seul signe peut être seul, celui du sommet. Ce n'est pas Dieu, qui est au-dessus de la figure et n'a pas de signe |
| 2 | 2 | deux bras en face | une dualité : les deux signes sont contraires (le rang 2 n'a pas de centre) ; ou une distinction, le centre et son cercle |
| 3 | 3 | la colonne, ou la ligne | les extrêmes et, entre eux, le point de l'axe. En colonne, ce qui est ; en ligne, ce qui devient. Le sujet au centre est un type de mot de trois parmi d'autres |
| 4 | 4 | les quatre bras, sans le centre | en face, deux paires de contraires ; autour, dans le sens horaire depuis le haut, un cycle, qui revient. Le centre, absent du mot, est ce autour de quoi il tourne |
| 5 | | la croix entière | les quatre et le centre |

Le sens de lecture : le haut d'abord, puis vers la droite ; d'où, sur la croix, le sens horaire. La
même figure lue à rebours dit le retour.

## Ce qui n'est pas décidé

- Les signes du triangle (flèches ou cercles) et le signe de l'Un.
- Le milieu du rang 3 dans un mot de deux : il n'a pas de contraire ; il n'y entre sans doute pas.
- Les mots de quatre : deux paires de contraires, ou une proportion (les deux du milieu, moyens
  des deux extrêmes, comme les éléments du *Timée*) ; ce ne sont pas les mêmes mots.
- Les noms des choses manifestées (le feu, le démon) : des participations aux principes, chacune
  avec sa formule ; à un degré ou à plusieurs.

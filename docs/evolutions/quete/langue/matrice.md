# La matrice de trois : où s'écrivent les mots

> Ce qui a été décidé sur la grille 3 × 3, la croix qu'on y occupe, et ce que dit chaque
> longueur de mot. Les triangles sont dans `triangles.yaml`, les mots dans `mots/`.

Un mot s'écrit dans une grille de trois sur trois. Le centre est le point où l'axe perce le
plan ; la colonne est l'axe, le haut, le milieu, le bas ; la ligne est le plan, l'avant, le
présent, l'après ; les quatre coins sont la seconde croix, les directions intermédiaires entre
les bras, comme les huit trigrammes autour du centre (de mémoire). La colonne dit ce qui est, la
ligne ce qui devient ; l'une est un principe dans l'être, l'autre dans le temps. Le centre est le
même point de l'axe, milieu dans l'être, présent dans le temps.

```
    ×   H   ×
    G   C   D
    ×   B   ×
```

## Ce que dit chaque longueur

La longueur d'un mot et sa figure dans la grille donnent sa lecture ; les figures sont celles
que la grille répartit symétriquement, et elles vont par paires selon l'orientation, comme le
mot de trois.

| Signes | Figure | Ce que la géométrie en dit |
|---|---|---|
| 1 | le centre | l'Un, la première détermination : un seul signe peut être seul, celui du sommet. Ce n'est pas Dieu, qui est au-dessus de la figure et n'a pas de signe |
| 2 | deux cases en face | une dualité : les deux signes sont contraires (le rang 2 n'a pas de centre) ; ou une distinction, le centre et son cercle |
| 3 | une colonne, ou une ligne | les extrêmes et, entre eux, le point de l'axe. En colonne, ce qui est ; en ligne, ce qui devient. Le sujet au centre est un type de mot de trois parmi d'autres |
| 4 | les quatre bras (+), ou les quatre coins (×) | en face, deux paires de contraires ; autour, dans le sens horaire depuis le haut, un cycle, qui revient. Le centre, absent du mot, est ce autour de quoi il tourne |
| 5 | la croix pleine, ou le × plein | le cycle et son centre |
| 6 | deux lignes, ou deux colonnes | deux plans, celui d'en haut et celui d'en bas, sans ce qui les relie ; ou deux êtres côte à côte |
| 7 | le I, ou le H | le six et son lien : deux plans reliés par l'axe, le milieu comme intermédiaire du haut et du bas (les eaux d'en haut, les eaux d'en bas, le firmament, Genèse 1, 6-7) ; ou deux colonnes jointes par leur milieu, l'intermédiaire d'une opposition horizontale |
| 8 | le pourtour, sans le centre | le cercle entier autour du point : les huit directions |
| 9 | la grille pleine | le tout, le centre et tout ce qui l'entoure |

Le sens de lecture : le haut d'abord, puis vers la droite ; d'où, sur la croix, le sens horaire. La
même figure lue à rebours dit le retour.

## Ce qui n'est pas décidé

- Les signes du triangle (flèches ou cercles) et le signe de l'Un.
- Le milieu du rang 3 dans un mot de deux : il n'a pas de contraire ; il n'y entre sans doute pas.
- Les mots de quatre : deux paires de contraires, ou une proportion (les deux du milieu, moyens
  des deux extrêmes, comme les éléments du *Timée*) ; ce ne sont pas les mêmes mots.
- Ce que disent les coins pris seuls, et le × plein.
- Les noms des choses manifestées (le feu, le démon) : des participations aux principes, chacune
  avec sa formule ; à un degré ou à plusieurs.
